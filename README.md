# Graph Game

Игра-головоломка: на экране отрисовывается взвешенный граф (SVG). Игрок кликами по узлам
строит путь от стартового узла до целевого и старается найти путь минимального веса.
Победа засчитывается, если вес построенного пути совпал с результатом алгоритма Дейкстры.

## Стек

- React 18 + TypeScript 5 (strict)
- Vite
- SVG-рендеринг графа (без Canvas)
- Vitest + Testing Library

## Структура проекта

```
├── index.html
├── vite.config.ts     # Vite + конфигурация Vitest (test.*)
├── vitest.setup.ts    # подключение @testing-library/jest-dom/vitest
├── tsconfig.json      # один TS-проект (src + конфиги), noEmit
└── src/
    ├── main.tsx
    ├── App.tsx
    ├── lib/
    │   ├── graph/     # types, generator, random, алгоритмы (dijkstra, bfs, adjacency, path-utils, min-heap)
    │   └── game/      # доменная логика: состояние, редьюсер, счёт, параметры партии, сессия

    ├── components/    # SVG-рендеринг графа и UI (PascalCase)
    └── test/          # общие тестовые фикстуры
```

## Соглашения

- Тесты лежат рядом с исходниками (`graph-generator.ts` + `graph-generator.test.ts`).
- Файлы — `kebab-case`, React-компоненты — `PascalCase`.
- Запрещён `any`; все типы объявлены явно.
- Каждая функция-алгоритм имеет JSDoc с пометкой сложности.
- Граф всегда связный (проверяется после генерации).

## Конфигурация TypeScript

Проект использует один `tsconfig.json` с `noEmit: true`, который покрывает `src`,
`vitest.setup.ts` и `vite.config.ts`. Проверка типов выполняется через `tsc --noEmit`
(и в `npm run build`), поэтому `tsc` ничего не эмитит в репозиторий и не оставляет
`*.tsbuildinfo`. `vite.config.ts` типизируется в том же проекте — отдельный
`tsconfig.node.json` не нужен.

## Правила игры

1. Стартовый узел отмечен зелёным, целевой — красным.
2. Клик по узлу, смежному с концом пути, продлевает путь; клик по предпоследнему
   узлу откатывает последний шаг.
3. «Подсказка» показывает эталонный путь (не больше 3 раз за партию) и уменьшает счёт.
4. «Проверить» доступно, когда путь дошёл до целевого узла.

Счёт считается в `src/lib/game/scoring.ts`: за оптимальный путь — 1000, за более
тяжёлый — 200, минус 50 за каждую единицу превышения веса и минус 100 за каждую
подсказку; счёт не опускается ниже нуля.

## Статус

Реализация завершена: граф, алгоритмы, игровая логика и интерфейс работают,
`npm run build` и `npm test` проходят без ошибок.

- `src/lib/graph` — типы, детерминированный генератор (`graph-generator`, `random`),
  алгоритмы (`dijkstra` с бинарной кучей `min-heap`, `bfs`, `adjacency`, `path-utils`).
- `src/lib/game` — состояние партии (`game-state`), чистый редьюсер (`game-reducer`),
  подсчёт счёта (`scoring`), параметры партии (`match`) и статистика сессии (`game-session`).
- `src/hooks` — `use-graph-game` (React-обвязка над редьюсерами), `use-svg-layout` (раскладка SVG).
- `src/components` — SVG-рендеринг графа и панели управления, статуса и счёта.
